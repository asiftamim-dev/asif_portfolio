ASIF TAMIM — PORTFOLIO WEBSITE

FILES
- index.html: responsive portfolio website
- assets/asif-tamim.png: clean transparent portrait used in the hero section
- assets/Asif_Tamim_CV.pdf: local CV copy retained as a backup

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Keep the assets folder beside index.html; the portrait uses this relative path.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository (for example: asif-tamim-portfolio).
2. Upload index.html and the complete assets folder (not just the files inside it).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide the public website address after deployment.

LINKS INCLUDED
- LinkedIn profile and phone link
- Email link opens a pre-addressed Gmail compose window
- Four Google Drive project links taken from the CV's embedded hyperlinks
- All CV buttons use the supplied Google Drive file link as a direct-download link

IMPORTANT
- In Google Drive, set the CV's General access to Anyone with the link (Viewer) if recruiters should be able to access it without requesting permission.
- Upload the entire folder structure to GitHub Pages so assets/asif-tamim.png remains available.
- Google Fonts are loaded online; fallback fonts are used offline.
- Portfolio facts and project descriptions are based on the supplied CV.
